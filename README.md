# JacobianPINN
Open-source library for a series of physics-informed neural networks to approximate Jacobian matrices. The current version allows users to evaluate 2x2 Jacobian matrices (standard $(x,y)$ functions) using any combination of sine, exponential, or power rule derivatives.

A PyPI release is upcoming. 

# Limitations
This release is just a proof-of-concept demo. More work will be done to refine existing models.
